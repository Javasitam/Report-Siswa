Website Biodata Murid

Website untuk belajar cara memakai Card dalam Visual Studio Code.

Tentang Project

Website biodata ini dibuat sebagai media sederhana untuk menampilkan informasi pribadi saya secara digital dalam bentuk halaman web yang terorganisir. Informasi yang ditampilkan meliputi biodata, kepribadian, dan hobi saya. Selain berfungsi sebagai sarana pengenalan diri, website ini juga melatih kemampuan dasar dalam menyusun struktur halaman, mengatur tampilan visual, serta membuat layout yang nyaman, khususnya dalam mempelajari cara memakai kode card. Dalam proses pembuatannya, website ini menggunakan HTML sebagai dasar struktur halaman, CSS untuk mengatur tampilan dan desain visual, serta framework Bootstrap untuk membantu pembuatan layout yang lebih rapi, modern, dan responsif. Komponen Bootstrap seperti card group dan button group digunakan agar tampilan website terlihat lebih terstruktur dan menarik. Dengan adanya website biodata ini, saya dapat mempresentasikan informasi pribadinya secara lebih interaktif dibandingkan menggunakan teks biasa.
